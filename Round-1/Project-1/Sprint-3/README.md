## 🏃 Sprint 3 — Data & Business Features

**Weeks 5–6 · Project 1: E-Commerce MVC**

### 🎯 Goal

Complete the e-commerce application by implementing production-like business features and mastering advanced Entity Framework Core.

---

## 📚 Concepts

- Fluent API
- Entity Configurations
- Soft Delete
- Global Query Filters
- MailKit
- HTML Email Templates
- Orders
- Reviews
- Stripe (Optional)

---

## 📝 Features

### 🗄️ Advanced Data Layer

Improve the database layer.

- Configure entities using Fluent API
- Implement Soft Delete
- Apply Global Query Filters
- Add CreatedAt & UpdatedAt
- Restore archived products
- Optimize queries

---

### 📦 Orders & Checkout

Implement the order lifecycle.

- Checkout page
- Order summary
- Delivery information
- Create Order & Order Items
- Fake payment workflow
- My Orders page

---

### 📧 Email Integration

Send transactional emails.

- Welcome Email
- Order Confirmation Email
- HTML Email Templates
- SMTP configuration using MailKit

---

### ⭐ Product Reviews

Allow customers to review products.

- Rate products
- Write reviews
- Edit own review
- Delete own review
- Prevent duplicate reviews
- Display average rating

---

### 💳 Bonus (Optional)

Integrate Stripe Sandbox.

- Create Payment Intent
- Complete payment
- Finalize order
- Send confirmation email

---

## ✅ Deliverable

A complete MVC E-Commerce application featuring authentication, shopping cart, checkout, orders, reviews, emails and advanced EF Core.

🎉 **Project 1 Complete**
